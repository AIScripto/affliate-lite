# CDH-002: Hard-coded colours are widespread (197 hex, 76 rgb, 415 raw Tailwind classes)

**Severity:** Low  
**Status:** Closed as controlled

## Why it was left
A check script (`npm run check:colors`) already blocks any new raw colour; each file can only get cleaner. 479 remain in 75 files. The low-count files are black scrims, shadows, white chips on gradient headers and star amber, which look the same in every theme on purpose. The big files hold level colours that carry meaning (`types/communication.ts`, `types/behavioral.ts`), print output (`pdfGenerator.ts`) and a deliberately dark panel (`CefrDocumentationTab.tsx`).

## Risk of leaving it
None for users. A raw colour does not adapt to a new theme, that is all.

## When to revisit
If you want a full theme-safe code base.

## What to do then
First add a few design tokens for overlays and dark panels (a design decision). Then convert in small batches of files, with before and after screenshots in light and dark mode, and lower the baseline with `npm run check:colors -- --update`.

## Needed from you
A design decision on the new tokens, only if you want the cleanup.
